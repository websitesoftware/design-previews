This public repository contains only compiled static review sites, self-hosted fonts and licenses, and review thumbnails. The original application source repository and its history remain private. No custom domain is configured, so the live marketing site is unaffected.

Preview pages request no indexing using robots meta tags. They are publicly accessible to anyone with the link, without sign-in. Enquiries prepare an email locally; sending is a separate action in the visitor's email app.

Direction 04 is published from the private site repository with `node scripts/publish-preview.mjs`.
